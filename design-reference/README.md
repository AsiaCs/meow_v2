# design-reference/

Drop this whole folder into the root of the meow repo before running the redesign brief. It's referenced explicitly by filename in `meow-ui-redesign-prompt.md` — Claude Code should open these with its image/file-reading tool during the matching phase, not just read the text descriptions in the brief.

## hero-references/ — Phase 1, section 4c (marketing/hero-section structure)
Used for meow's landing/home/onboarding hero. Look at composition, hierarchy, and how much visual weight the image vs. the text vs. the CTA gets in each.

- `01-immersive-uiwiki.png` — dark tech gradient hero, single bold headline + one CTA, minimal nav
- `02-pixel-bloom-ai.png` — dual-CTA hero (primary + secondary), nav with a dropdown
- `03-winzy-travel-booking.png` — functional widget (search/booking form) overlaid directly on a photo hero
- `04-mansi-ux-saas.png` — announcement pill above headline, single CTA, trust-logo row beneath the fold
- `05-flower-studio-editorial.png` — editorial hero: large headline, byline/date metadata line, minimal nav

## hero-layouts/ — Phase 1, section 4c (in-app hero/card skeleton)
A labeled wireframe (mobile 9:16) showing the region breakdown of an app hero/card unit: Navigation → Title → Supporting text/caption → CTA → large Image → "save for later." Use as a layout skeleton for meow's primary content card or home hero unit, not a literal template.

- `01-hero-layout-a.png` through `04-hero-layout-d.png` — four frames/angles of the same labeled skeleton

## color-palettes/ — Phase 1, section 4b (color system)
- `CHOSEN-lets-be-thinkers-haus.png` — **the palette this build is locked to.** Look at it directly for the actual mood (grain texture, how the rose accent sits against the dark teal/slate, contrast relationships) beyond just the five hex values in the brief.
- `alt-*.png` — the six reference/alternate palettes documented in the brief (Futuristic Minimalism, Natural Calm, Study Hard, Minimal Colors by Dumma, Niche Collection S&S, The Extra O, Ctrl wallet color-combo example). Not for this build — kept for the record.
